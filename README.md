# Smart Waste · SPU ขอนแก่น

เว็บต้นแบบระบบแจ้งและติดตามปัญหาขยะล้นภายในมหาวิทยาลัย (เลือกจุด → ถ่ายรูป → ส่ง) ใช้แผนผังวิทยาเขต SPU ขอนแก่น อาคาร 1–4 เป็นแผนที่

## ฟีเจอร์
- **ผู้แจ้ง:** แจ้งขยะล้น (ต้องแนบรูป) ติดตามสถานะ รายการ แผนผังวิทยาเขต Dashboard Chatbot
- **เจ้าหน้าที่:** รับงาน เปลี่ยนสถานะ แนบรูปหลังเก็บ ดูข้อความ LINE
- **ผู้ดูแลพื้นที่:** ภาพรวมทุกโซน รับ Escalation มอบหมายงานใหม่
- **แผนผังวิทยาเขต:** หมุดถังขยะตามสถานะ ค้นหาห้อง/อาคาร/รหัสถัง ซูม รายการห้องสำคัญของอาคาร 1–4
- **Dashboard:** เริ่มต้นว่าง แสดงสถิติเมื่อมีการแจ้งเรื่องจริง (วันนี้ / 7 วัน / เดือนนี้) ดาวน์โหลด CSV
- กฎระบบ: รวมเรื่องซ้ำของถังเดียวกันภายใน 30 นาที เตือนนาทีที่ 20 ส่งต่อผู้ดูแลนาทีที่ 30
- ปุ่ม "เร่งเวลา +10 นาที" ใช้ทดสอบการเตือนและ Escalation

## ข้อมูล
- เก็บในเบราว์เซอร์เครื่องนั้น (localStorage) รีเฟรชแล้วข้อมูลยังอยู่
- ท้ายหน้ามีปุ่ม "โหลดข้อมูลตัวอย่าง" และ "ล้างข้อมูลทั้งหมด"
- แก้ตำแหน่งถัง/ห้องได้ที่ต้น `app.js` (`BINS`, `BLD`) พิกัดเป็นพิกเซลบน `assets/campus-map.png`

## ข้อจำกัดของต้นแบบ
- ไม่ส่ง LINE จริง แสดงเป็นหน้าตาข้อความเท่านั้น
- ตำแหน่งถังขยะเป็นตำแหน่งตัวอย่างบนแผนผัง
